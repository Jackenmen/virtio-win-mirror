# virtio-win-mirror

This repository mirrors select virtio-win artifacts from https://fedorapeople.org/groups/virt/virtio-win/
to improve reliability when using them as a dependency. The above link does not have any mirrors
so any downtime prevents anyone from accessing it.

The files are grouped under this repository's GitHub Releases and have been taken directly
from the above link with no modifications.
